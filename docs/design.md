# SciType 数据边界与用户自定义方向

## 当前原则

SciType 负责把用户选择的快捷命令转换为符号，但不规定用户必须使用哪一种
缩写，也不根据某个专业中的含义为符号建立不可更改的固定命令。

V0.3a 明确分开以下三层。

### 1. 符号目录

包内 `src/scitype/data/symbols.json` 是与 trigger 无关的符号目录。每条
记录包含：

- 稳定的 `id`；
- 面向用户的符号名称；
- 分类；
- 输出字符或单光标模板。

例如 `γ`、`Γ`、`σ`、`φ` 和 `∫${cursor}dx` 都是独立目录内容。
目录记录不包含用户缩写，也不把符号限定为数学、机械、统计或其他学科中的
某一个含义。

### 2. 用户快捷绑定

快捷绑定与符号目录分离。同一个输出可以被不同用户用不同缩写绑定，也可以
拥有多个别名。

V0.5b 首先实现最小的直接 `trigger → replacement` 底层。用户配置保存在：

```text
%LOCALAPPDATA%\SciType\user_bindings.json
```

用户文件不得与 Python 包内资源混放，也不得在 SciType 升级时被覆盖。
用户文件是带 `schema_version` 的 UTF-8 JSON 对象；`bindings` 数组中的
每项包含 `trigger`、`replacement` 和 `enabled`。这使未来界面能够稳定
新增、编辑、删除和停用单项，并为格式迁移提供明确版本边界。

基础词典与扩展包的独立屏蔽保存在：

```text
%LOCALAPPDATA%\SciType\catalog_masks.json
```

该文件只保存 schema 版本和确定排序的 `disabled_triggers`，不会向旧版严格
`user_bindings.json` 增加字段。

程序启动时先严格加载包内默认绑定和可选的本地只读扩展包，再加载可选用户
文件。启用的同名用户项覆盖所有词典来源；停用的同名用户项从有效集合中
移除该 trigger，最后再应用独立词典屏蔽。缺少用户文件或 masks 文件都是
合法情况。任一可选文件损坏时原文件保持不变，其他有效来源仍可使用；只有
包内基础词典本身损坏才阻止 Hook 安装。

有效集合和用户文档以不可变快照传递。显式 reload 成功会返回新快照，失败
则保留旧快照；当前 Hook 尚未接入运行时快照交换，因此保存后明确要求重启。
V0.5b 不实现文件监听、后台轮询、`trigger → symbol_id` 用户格式或界面。
V0.6 在不改变这些底层语义的前提下增加独立设置程序。

### 3. 官方预设与当前兼容示例

`src/scitype/data/default_bindings.json` 目前只提供开箱验证和向旧版本兼容
所需的默认示例。它不是唯一缩写标准。`/xw → φ` 因兼容性暂时保留，同时
提供按字母名称组织的 `/fi → φ`。

未来可以提供可选预设，但预设应允许用户导入、修改或删除，不能成为解析器
核心规则。

## V0.6 自定义界面与未来方向

V0.6 已实现：

1. “我的绑定”“词典”“设置”三个独立一级入口；
2. 搜索用户绑定，填写自己的缩写和静态输出；
3. 预览最终输出和单个光标位置；
4. 通过配置服务检测 trigger 冲突；
5. 新增、修改、删除和停用绑定；
6. 只读查询基础词典和本地 JSON 扩展包；
7. 从词典词条创建用户自定义版本；
8. 验证并安全导入本地扩展包。

本地扩展包位于 `%LOCALAPPDATA%\SciType\packs\`。它们只有 JSON 数据，
不能包含可执行逻辑。扩展词条与基础词典、其他包或系统保留 trigger 冲突
时会被确定性标记，不依赖加载顺序覆盖。用户绑定的 enabled、覆盖和屏蔽
语义保持不变。

完整预设管理、用户配置导入导出、在线扩展商店和自动热重载仍是未来方向。
V0.6 不增加化学式、化学反应及化学专用结构。
