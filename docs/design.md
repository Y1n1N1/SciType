# SciType 数据边界与未来自定义方向

## 当前原则

SciType 负责把用户选择的快捷命令转换为符号，但不规定用户必须使用哪一种
缩写，也不根据某个专业中的含义为符号建立不可更改的固定命令。

V0.3a 明确分开以下三层。

### 1. 符号目录

包内 `src/scitype/data/symbols.json` 是与 trigger 无关的符号目录。每条
记录包含：

- 稳定的 `id`；
- 面向用户的符号名称；
- 分类；
- 输出字符或单光标模板。

例如 `γ`、`Γ`、`σ`、`φ` 和 `∫${cursor}dx` 都是独立目录内容。
目录记录不包含用户缩写，也不把符号限定为数学、机械、统计或其他学科中的
某一个含义。

### 2. 用户快捷绑定

快捷绑定负责保存 `trigger → symbol_id`，也可以在未来支持
`trigger → output`。同一个符号可以被不同用户用不同缩写绑定，也可以拥有
多个别名。

未来用户配置应保存在：

```text
%LOCALAPPDATA%\SciType\
```

用户文件不得与 Python 包内资源混放，也不得在 SciType 升级时被覆盖。
V0.3a 尚未读取或写入用户绑定文件。

### 3. 官方预设与当前兼容示例

`src/scitype/data/default_bindings.json` 目前只提供开箱验证和向旧版本兼容
所需的默认示例。它不是唯一缩写标准。`/xw → φ` 因兼容性暂时保留，同时
提供按字母名称组织的 `/fi → φ`。

未来可以提供可选预设，但预设应允许用户导入、修改或删除，不能成为解析器
核心规则。

## 未来自定义界面

后续自定义界面的核心功能计划包括：

1. 搜索或选择符号；
2. 填写用户自己的缩写；
3. 预览最终输出和光标位置；
4. 检测 trigger 冲突；
5. 新增、修改和删除绑定；
6. 导入及导出用户配置。

这些功能不属于 V0.3a。本阶段不实现自定义界面、预设管理界面或化学式、
化学反应及化学专用结构。
