## 普通使用场景

只要遵守完整许可证及其中的署名和通知要求，个人、学校、教师、研究人员、
公司员工和其他组织都可以免费使用 SciType。学习、教学、科研、工作或其他
营利活动本身，并不会自动变成 Commons Clause 所定义的“Sell”。

例如，以下场景属于允许范围：

- 老师在付费网课中使用 SciType 输入公式；
- 公司员工使用 SciType 完成工作；
- 学生、科研人员和工程师免费使用 SciType；
- 查看、学习或修改源代码；
- 按许可证要求保留通知后分发源代码或修改版本；
- 将 SciType 集成到加入大量独立功能、具有实质性额外价值的更大产品中。

## 需要另行商业授权的场景

未经作者事先书面许可，以下行为不在当前许可证授权范围内：

- 将 SciType 改名后直接收费售卖；
- 将 SciType 本身打包成付费下载；
- 提供主要价值实质上就是 SciType 功能的付费订阅或商业服务；
- 只进行换图标、改名称或其他轻微修改，便作为竞品收费发行；
- 删除许可证、版权声明或 Commons Clause 通知后再分发。

如需上述商业授权，请通过 GitHub Issues 联系项目作者。

## 使用 SciType 工作赚钱与出售 SciType 的区别

Commons Clause 不是对一切营利活动的笼统禁止。

例如，教师使用 SciType 制作付费课程、工程师在受薪工作中输入公式，价值
主要来自教师的教学内容或工程师的专业工作，而不是向第三方出售 SciType
本身。这类使用属于允许范围。

相反，如果收费产品、下载、订阅或服务的价值全部或实质上来自 SciType 的
功能，即使进行了改名、换图标或少量修改，也可能属于许可证中定义的
“Sell”，需要事先取得作者书面许可。

将 SciType 作为组成部分集成进真正增加了独立、实质性价值的更大产品，与
出售主要价值来自 SciType 本身的版本不同。具体边界应依据 LICENSE 中的
“Sell”定义判断。
