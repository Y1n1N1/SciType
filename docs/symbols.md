# SciType 理科符号速查表

本表列出 V0.3a 随包提供的兼容默认示例，不是唯一缩写，也不是要求用户
遵守的官方标准。内置示例尽量按符号名称组织；同一个符号在数学、物理、
统计等领域可能具有不同含义，SciType 不把某个专业含义写死在符号上。

专业名称和个人习惯缩写将在后续用户自定义词库中支持。

输入完整命令后，按 `Space` 或 `Enter` 确认。按 `Esc` 取消本次符号
输入，按 `Backspace` 编辑缩写。输入 `//` 可得到普通斜杠 `/`。

SciType 运行期间可随时按 `Ctrl + Alt + Q` 退出程序。

## 结构输入

| 中文名称 | 输入缩写 | 输出效果 |
|---|---|---|
| 普通斜杠 | `//` | `/` |
| 小写斐兼容别名 | `/xw` | `φ` |
| 绝对值 | `/jdz` | <code>&#124;&#124;</code>，光标位于两条竖线之间 |
| 积分 | `/jf` | `∫dx`，光标位于 `∫` 与 `d` 之间 |
| 根号 | `/gh` | `√()`，光标位于括号内 |

## 希腊字母

`d` 前缀在当前兼容示例中表示大写。`/xw` 仅为旧版本兼容别名，
更中性的字母名称示例是 `/fi`。

| 中文名称 | 输入缩写 | 输出效果 |
|---|---|---|
| 小写伽马 | `/gm` | `γ` |
| 大写伽马 | `/dgm` | `Γ` |
| 小写西格玛 | `/sg` | `σ` |
| 大写西格玛 | `/dsg` | `Σ` |
| 小写斐 | `/fi` | `φ` |
| 大写斐 | `/dfi` | `Φ` |
| 小写欧米伽 | `/og` | `ω` |
| 大写欧米伽 | `/dog` | `Ω` |
